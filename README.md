# tayyar-CV · Portfolio-Variante

Vorhandene Fassung der persönlichen Website von Tayyar Eren.

**Zentraler Einstieg:** [Portfolio](https://github.com/TayyarEren/portfolio) · [Projektübersicht](https://github.com/TayyarEren/tayyareren/blob/main/PROJEKTE.md)

## Einordnung

Eigenständige CV-/Portfolio-Fassung mit einer zusätzlichen PNG-Datei. Die Kontaktverweise führen zu E-Mail, GitHub und LinkedIn von Tayyar Eren. Die referenzierte Datei `profile.jpg` fehlt.

## Lokal ansehen

Repository über **Code → Download ZIP** herunterladen, entpacken und die Datei `index.html` im Browser öffnen. Die Website verwendet HTML, CSS und JavaScript.

Diese Fassung bleibt zum Vergleich erhalten. Berufliche Angaben und Kontaktinformationen können einen früheren Stand abbilden.
